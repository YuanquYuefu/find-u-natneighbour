# find-u-natneighbour — NAT VPS 鄰居普查與活躍度探測工具

**v1.3.1** · 倉庫：[YuanquYuefu/find-u-natneighbour](https://github.com/YuanquYuefu/find-u-natneighbour) · 腳本：[nat.sh](nat.sh) · 項目約定：[project.md](project.md)

這是一個適用於各類 **KVM / LXC / OpenVZ / Incus** 架構 NAT VPS（「NAT 小雞」）的通用二層鄰居普查與活躍度分析腳本。只需透過一行指令下載安裝（支援 **先 IPv4 後 IPv6 自動容錯** 並顯示即時下載進度），之後在終端機直接輸入 `nat` 即可喚出互動菜單，不僅能統計真實買家鄰居數量（含 `/16` 跨子網二層廣播域），還能透過 **微延遲抖動 + 繁忙佔空比（Duty Cycle %）** 自動鑑別鄰居是 **「吃灰閒置」**、**「探針/個人自用」** 還是 **「疑似跑機場/二次轉售」**。

---

## 一鍵安裝與使用

### 1. 下載並註冊 `nat` 快捷指令（先 IPv4 後 IPv6 自動容錯）

在你的 LXC 或 KVM 機器終端機（SSH）中執行以下指令即可完成安裝（優先使用 IPv4 下載，若為純 IPv6 環境則自動切換 IPv6 下載，並顯示完整下載進度）：

```bash
(wget -4 --timeout=10 --tries=2 -O /usr/local/bin/nat https://raw.githubusercontent.com/YuanquYuefu/find-u-natneighbour/main/nat.sh || wget -6 --timeout=10 --tries=1 -O /usr/local/bin/nat https://raw.githubusercontent.com/YuanquYuefu/find-u-natneighbour/main/nat.sh) && chmod +x /usr/local/bin/nat
```

*(或者下載至當前目錄並直接執行：` (wget -4 --timeout=10 --tries=2 -O nat.sh https://raw.githubusercontent.com/YuanquYuefu/find-u-natneighbour/main/nat.sh || wget -6 --timeout=10 --tries=1 -O nat.sh https://raw.githubusercontent.com/YuanquYuefu/find-u-natneighbour/main/nat.sh) && bash nat.sh`，腳本首次運行時也會自動將自己註冊到 `/usr/local/bin/nat`。)*

### 2. 輸入 `nat` 喚出互動菜單

安裝完成後，隨時在終端機輸入：

```bash
nat
```

即可喚出互動式操作菜單：

```text
========================================================================
🛰️  NAT 鄰居普查與活躍度探測工具 v1.3.1  (架構: KVM | 介面: eth0)
========================================================================
📍 本機內網 IP : 192.168.30.108 (/24)   MAC: 6a:1f:xx:xx:xx:xx
🛣️  內網預設網關: 192.168.30.1           共享公網 IPv4: 114.36.x.x
------------------------------------------------------------------------
  0. 退出
  1. 看看你有多少鄰居
  2. 看看此時你有多少活躍鄰居
  3. 先執行1再執行2
  4. 檢查並更新
  5. 刪除
------------------------------------------------------------------------
請輸入選項 [0-5]:
```

* **`0. 退出`**：退出腳本。
* **`1. 看看你有多少鄰居`**：約 2 秒快速完成二層 ARP 鄰居普查與真實買家識別，列出所有在線買家鄰居並自動排除網關、母雞與老闆手動測試機。
* **`2. 看看此時你有多少活躍鄰居`**：自動定位當前在線鄰居並進行 50 次高頻微抖動採樣（約 7 秒），輸出母雞外網負載基準、各鄰居 **繁忙佔空比 %** 與 **機場/自用行為診斷排行榜**。
* **`3. 先執行1再執行2`**：先完整執行選項 `1`（輸出鄰居清單與總人數），再無縫接續執行選項 `2`（直接沿用剛掃描的鄰居名單進行活躍度採樣排行）。
* **`4. 檢查並更新`**：強制透過先 IPv4 後 IPv6 自動容錯從 GitHub 拉取最新版本的 `nat.sh` 並自動覆蓋更新 `/usr/local/bin/nat`。
* **`5. 刪除`**：一鍵移除系統中的 `/usr/local/bin/nat` 全局快捷指令與本地腳本。

## 命令列參數與免菜單快捷模式

除了直接輸入 `nat` 進入互動菜單外，也支援透過命令列參數直接執行指定模式：

| 指令 / 參數 | 行為說明 |
| :--- | :--- |
| `nat` | **互動菜單模式（預設）**：喚出 `0 ~ 5` 數字菜單 |
| `nat 1` 或 `nat -q` / `--quick` | 免菜單直接執行 **「1. 看看你有多少鄰居」**（約 2 秒完成） |
| `nat 2` 或 `nat --active` | 免菜單直接執行 **「2. 看看此時你有多少活躍鄰居」** |
| `nat 3` 或 `nat --both` | 免菜單直接執行 **「3. 先執行1再執行2」** |
| `nat 4` 或 `nat -u` / `--update` | 免菜單直接執行 **「4. 檢查並更新」**（先 IPv4 後 IPv6 自動容錯更新） |
| `nat 5` 或 `nat --uninstall` | 免菜單直接執行 **「5. 刪除」**（移除 `/usr/local/bin/nat`） |
| `nat -c 100` | 自訂每台鄰居的高頻 Ping 採樣次數（預設 `50` 次，最少 `5` 次） |
| `nat -a` 或 `nat --all` | 將自動排除的老闆/母雞系統節點也一併納入活躍度排行榜 |
| `nat --install` | 手動將本腳本安裝或更新至 `/usr/local/bin/nat` |
| `nat -h` 或 `nat --help` | 顯示參數與菜單說明 |

## 核心機制與真實買家識別邏輯

### 1. 為什麼用二層 ARP 而不是單純看 Ping？
在同一台母雞的虛擬交換機（Linux Bridge / Open vSwitch / iKuai 內網段）下，所有同區鄰居位於同一個二層廣播域：
* 即使某位鄰居在系統內開啟了防火牆 **禁 Ping（阻擋 ICMP Echo）**，只要對該網段發送探測包，作業系統核心仍會在二層回應 ARP（`lladdr` MAC 位址）。
* 本腳本結合 **併發 ICMP 探測 + `ip neigh` ARP 表解析**，能 100% 抓出開啟禁 Ping 防火牆的「隱身鄰居」（標記為 `🛡️ 禁Ping(ARP在線)`）。

### 2. 如何自動區分「真實買家」與「老闆 / 母雞系統機」？
在 NAT 母雞網段中，除了真實買家外，往往還存在軟路由網關（如 iKuai / RouterOS）、母雞橋接介面、老闆手動開的測試機或 Looking Glass 探針機。腳本內建多維度啟發式過濾邏輯：

1. **預設路由與 Router 宣告排除**：
   自動讀取 `ip route` 預設網關（如 `.1`、`.254`）以及 ARP 表中帶有 `router` 標記的節點，歸類為 `網關/路由節點`。
2. **面板隨機 MAC（LAA）vs 母雞原生固定 OUI 比對**：
   * 現代財務與被控面板（如 Paymenter、Virtualizor、Convoy 等）自動開通買家 VM 時，通常會生成 **本地管理隨機 MAC（Locally Administered MAC，第一字節第二碼為 `2 / 6 / a / e`）**。
   * 而老闆在 Proxmox VE (PVE)、KVM 或 Xen 後台手動建立的軟路由、探針或測試機，則會帶有虛擬化官方固定 OUI（例如 PVE 的 `bc:24:11`、QEMU 的 `52:54:00`）。
   * 當腳本偵測到本機或同網段買家群聚使用 LAA 隨機 MAC 時，會自動將帶有母雞原生固定 OUI（如 `bc:24:11`）或實體硬體網卡 OUI 的機器識別為 **「老闆/系統手動機」** 並予以排除，不計入買家鄰居人數。
3. **純固定 OUI 環境的保留位識別**：
   若該商家所有容器/VM 統一使用相同廠商 OUI，腳本會進一步比對特殊管理尾號（如 `.2` 宿主橋接位、`.100` 整數探針位且 OUI 異於買家池），避免誤算系統節點。

### 3. 如何鑑別鄰居是「正常個人自用」還是「跑機場 / 二次轉售」？
在二層交換機環境下，本工具對每台鄰居進行 50 次錯峰高頻採樣，並同時計算三項關鍵指標：**標準差抖動（`mdev`）**、**剔除極值後的連續抖動（`trim_mdev`）** 與 **繁忙佔空比（`Busy Duty Cycle %`，即 50 包中有多少包發生佇列延遲尖峰）**：

* **💤 吃灰閒置（靜止）**：抖動 `mdev` 與網關背景抖動相當，繁忙佔空比 `0% ~ 2%`，代表完全空閒。
* **⚡ 間歇微脈衝（探針/輕度自用）**：50 個封包中只有零星 1~4 個封包（佔空比 `< 10%`）出現尖峰，剔除單一尖峰後 `trim_mdev` 極低。這代表小雞僅有哪吒探針心跳、背景定時任務或極輕量的網頁瀏覽。
* **🔥 活躍使用中（自用串流/下載）**：抖動與連續抖動顯著高於網關基準，且繁忙佔空比介於 **`10% ~ 28%`**（50 包中有 5~14 包出現排隊）。這是典型的個人正在看 4K YouTube / Netflix 串流分片緩衝或一般檔案下載，不會長期塞死母雞。
* **🚨 疑似機場 / 持續大流量（高佔空比 `≥ 30%`）**：當某台小雞被拿去掛載機場後端（多人同時併發 TLS 握手與轉發）或長期跑滿頻寬時，其虛擬網卡軟中斷佇列會長期處於飽和狀態，導致 **50 包中有 15 包以上（繁忙佔空比 `≥ 30% ~ 80%+`）持續出現高延遲**，且 `trim_mdev` 與 `avg` 雙雙飆高。若多次複測某台鄰居皆顯示 `🚨 疑似機場/持續大流量`，即可直接截圖作為發工單證據。

## 版本變更記錄

* **v1.3.1**：
  * **修復低配額 LXC / Incus 容器 `fork: retry: Resource temporarily unavailable` 報錯**：新增 `cgroup v2 pids.max` 與 `ulimit -u` 自適應併發控制器（自動解除 `systemd` 對 `user-0.slice` / `ssh.service` 的 33%/15% 子配額限制，移除巢狀子 Shell 並改用分批併發節流與 `-W 0.25` 快速超時）。
  * **新增 `/16` 等跨 `/24` 大網段二層廣播域完整鄰居普查**：結合 IPv6 二層全節點組播（`ff02::1%iface`）、LLMNR/DNS 反查與 `ip -4/-6 neigh` MAC 位址唯一鍵去重，支援在 `/16` 橋接環境（如 Incus `10.88.0.0/16`）下完整識別所有跨子網鄰居並進行二層微抖動採樣。
* **v1.3.0**：
  * 排行榜新增 **「繁忙佔空比 % (N包)」** 欄位與 **「機場/二次轉售 vs 個人自用」行為診斷引擎**：自動統計 50 次採樣中高延遲尖峰封包的佔比，精確區分 `💤 吃灰閒置`、`⚡ 間歇微脈衝 (探針/輕度自用)`、`🔥 活躍使用中 (自用串流/下載)` 與 `🚨 疑似機場/持續大流量 (高佔空比 ≥30%)`。
* **v1.2.1**：
  * 下載與自動更新容錯順序調整為 **先 IPv4 後 IPv6**（`wget -4 ... || wget -6 ...`）。
  * 修正活躍鄰居判定演算法：移除單純以單次封包峰值 `max` 直接判定活躍/輕度的激進條件，改為嚴格依據 **相對內網網關抖動倍數（`mdev`）+ 剔除極值後連續抖動（`trim_mdev`）** 雙重確認。
* **v1.2.0**：
  * 安裝與更新指令改為非靜默模式（顯示即時進度），並支援 IPv4 / IPv6 自動容錯下載。
  * 互動菜單新增 **`4. 檢查並更新`** 與 **`5. 刪除`** 兩個選項（亦支援 `nat 4` / `nat -u` 與 `nat 5` / `nat --uninstall` 直接執行）。
* **v1.1.0**：
  * 新增 `nat` 互動式數字菜單（`0. 退出` / `1. 看看你有多少鄰居` / `2. 看看此時你有多少活躍鄰居` / `3. 先執行1再執行2`），並支援執行後循環操作或透過 `nat 1`、`nat 2`、`nat 3` 免菜單直接呼叫。
  * 更新 GitHub 倉庫地址為 [`YuanquYuefu/find-u-natneighbour`](https://github.com/YuanquYuefu/find-u-natneighbour)。
* **v1.0.0**：
  * 初版發布：支援 KVM / LXC / OpenVZ 全環境自動偵測網卡、網關、虛擬化類型與外部共享公網 IPv4。
